# Dimensions — mémo boutique

Un **seul lien** (`https://a1soir.com/mensurations`), toujours le même, à copier depuis l’admin (Dimensions). Vous le collez dans un mail, WhatsApp, etc. — à une personne ou à un responsable qui le transmet.

La page n’est **pas dans les menus**, **pas dans le sitemap**, **noindex** (meta + en-tête HTTP) et **Disallow** dans `robots.txt`.

La page s’ouvre en **français**. On peut passer en **anglais** via la barre. On saisit **son** e-mail, on passe le captcha et on reçoit un **code**. Pas de choix femme / homme avant ça. Après le code : formulaire (femme / homme), puis les mesures. Langue et formulaire restent modifiables, y compris après envoi. On peut revenir plus tard modifier **sa** fiche.

Chaque fiche est visible dans **Dimensions** et sur le **compte client**.

Le formulaire est en **sections**. Une **petite silhouette animée** indique la zone à mesurer. Une photo en pied peut être jointe.
